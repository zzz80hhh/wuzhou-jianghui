# 五洲匠汇 · Five Continents Heritage Resonance

金砖五国非物质文化遗产数字藏品平台——以数字技术唤醒古老文明，让每一种非遗在数字时代被看见、被收藏、被传承。

## 在线体验

## 技术栈

- 纯前端：HTML + CSS + 原生 JavaScript（无框架依赖）
- Canvas 2D 渲染（珠绣网格、冰霜粒子）
- Web Audio API（音频分析与可视化）
- MediaRecorder API（视频录制）
- Content Security Policy 安全头
- 响应式设计，支持移动端触控

## 公益承诺

本项目数藏发行收益的 **10%** 将通过联合国教科文组织（UNESCO）相关基金，定向捐赠给金砖国家非遗传承人社区。
